Lab 2 — Pipelining & Branch Prediction

Lab 2 — Interactive Pipeline Laboratory

Goal: Build instruction sequences, identify data dependencies, simulate a 5-stage pipeline, investigate stalls and forwarding, and quantitatively evaluate processor performance.

Pipeline modeled: IF → ID → EX → MEM → WB

Primary data hazard modeled: RAW (Read After Write)
Architecture note: This simulator models a classic in-order 5-stage pipeline. WAR and WAW dependencies are displayed for educational purposes but are not treated as stalls in this pipeline model.

Experiment 1 — Build Your Own Instruction Sequence

Drag instructions from the palette into the processor program. You may reorder instructions by dragging them within the program.

New: Editable Registers
Each instruction has editable register operands. Change the destination and source registers to intentionally create or eliminate RAW dependencies. The simulator uses the registers you select—not a fixed instruction template— when calculating hazards, stalls, forwarding, and CPI.

Tip: Try changing only one register and then re-run the simulation. Observe how the dependency table and pipeline timing change.

Instruction Palette

ADD R1 = R2 + R3
SUB R1 = R2 − R3
AND R1 = R2 & R3
OR R1 = R2 | R3
LW R1 = Memory[R2]
SW Memory[R1] = R2
BEQ Branch if R1 = R2
BNE Branch if R1 ≠ R2

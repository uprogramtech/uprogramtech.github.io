3. Cache Time Analysis

Estimate average memory access time (AMAT) and total access cycles. The number of sets is calculated from cache size, block size, and associativity. The timing equations below are intentionally simplified for classroom comparison; they are not a cycle-accurate processor or memory-system model.

Suggested experiments

  • Conflict misses: choose direct mapped and test a trace such as 0, 64, 0, 64, 128, 0, 64, 128 with a 16-byte block and a small cache.
  • Replacement policies: keep cache geometry and trace fixed, then compare LRU, FIFO, and Random.
  • Locality: compare sequential addresses (for example 0, 4, 8, 12, 16, 20, 24, 28) with a scattered trace.
  • AMAT: hold hit time and miss penalty constant and compare how changing hit rate affects AMAT.

Educational simplifications: the trace model treats every address as a read and does not model dirty bits or write traffic. The time-analysis model is separate from the trace simulator and uses the user-entered hit rate rather than deriving it from the trace.
